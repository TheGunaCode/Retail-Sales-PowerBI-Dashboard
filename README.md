# Retail Sales & Business Performance Analytics

## 📌 Project Overview

This project analyzes retail sales data using Microsoft Power BI to understand business performance, customer behavior, product sales, and profitability.

The dashboard helps users identify sales trends, evaluate product performance, and compare sales and profit across different regions.

## 🎯 Project Objectives

* Analyze total sales and total profit.
* Track monthly sales trends.
* Identify top-performing products and categories.
* Understand customer purchasing performance.
* Compare regional sales and profitability.
* Analyze profit margins and business performance.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Microsoft Excel

## 📊 Dashboard Pages

1. **Executive Overview** – Key performance indicators and overall business performance.
2. **Product Performance** – Product sales, category analysis, and top-performing products.
3. **Customer & Regional Analysis** – Customer performance and regional sales analysis.
4. **Detailed Analysis** – Detailed customer performance table and interactive analysis.

## 📈 Key Metrics

* Total Sales
* Total Profit
* Total Orders
* Profit Margin %
* Quantity Sold
* Customer Performance

## 📁 Project Files

* `Retail-Sales-Dashboard.pbix` – Power BI dashboard project file.
* `Screenshots/` – Dashboard screenshots and visualizations.

## 🚀 How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard pages and interact with the available filters and visuals.
